# وضعیت نهایی کد و قدم بعد — ۵ نوامبر ۲۰۲۶

## انجام‌شده

- مخزن عمومی دانشجویی و README منتشر شده‌اند.
- ۱۲۸ اجرای متمایز توسعه‌ها و ۱۲٬۸۰۰ دوره تأیید شده‌اند؛ ۹ نتیجهٔ مرجع دوباره شمرده نمی‌شوند.
- بررسی واقعی ویندوز دریافت شده است؛ ممیزی نمونه‌گیری و داوری نیز جداگانه موجود است.
- سه پاسخ واقعی Gemini و ۷۲ امتیاز دریافت و بررسی شدند. بررسی انسانی مستقل نداریم؛ پیش‌نویس قبلی با کمک AI بود.
- برای بررسی آفلاین جدول‌ها و شواهد خام داوری: `python verify_public_results.py` . این دستور آموزش یا درخواست API انجام نمی‌دهد.
- برای بررسی اجرای واقعی مدل در محیط ثابت، دستور جداگانهٔ `python verify_submission.py --runtime` پس از bootstrap موجود است.

## باقی‌مانده پیش از تحویل

گزارش ACL تهیه و پس از ممیزی اصلاح شده است؛ نسخهٔ بدون کاور ۸ صفحه متن اصلی و یک صفحه منابع دارد. به‌روزرسانی شواهد بازتولید و مستندات را اعمال کن و `python verify_public_results.py` را روی مخزن محلی دوباره اجرا کن. سپس منابع اخلاق واحد و آخرین توضیحات استاد را با گزارش تطبیق بده و PDF نهایی را بخوان. نبود بررسی انسانی مستقل، تفاوت برچسب‌ها و محدودیت oracle در متن صریح است.

چک‌لیست جاری و کامل در [RUBRIC_TRACKER.md](RUBRIC_TRACKER.md) و راهنمای ممتحن در [MARKER_GUIDE.md](MARKER_GUIDE.md) است. چک‌لیست‌های داخل پوشه‌های نتایج، سابقهٔ مراحل قبلی‌اند.

آموزش یا داوری تازه برای طرح فعلی لازم نیست. کد به‌تنهایی نمرهٔ کل ۴۰ را تعیین نمی‌کند؛ این نمره متعلق به مجموعهٔ شواهد و گزارش است.
