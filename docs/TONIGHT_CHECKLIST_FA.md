# چک‌لیست امشب، ۴ نوامبر ۲۰۲۶

## مبنای نمره

فایل رسمی «Assessment-Project-Final-Report» شش‌صفحه‌ای که دوباره فرستاده‌ای، همان نسخهٔ قبلی است: ۴۰ نمره و وزن ۴۰٪. سقف مسیر پروژهٔ پیش‌فرض در جدول ۳۲ است و مسیر پروژهٔ نوآورانه مجموعاً ۴۰. فایل ارسالی مبنایی برای ۳۰ نمره ندارد. اگر اعلان تازه‌ای مبنی بر تبدیل به ۳۰ وجود دارد، باید همان اعلان بررسی شود. کد به‌تنهایی کل نمره را تعیین نمی‌کند.

## وضعیت به‌روز پس از دریافت نتایج نمونه‌گیری

۱۸ اجرای جدید و دو نمونهٔ تازه مستقلاً تأیید شدند. مجموع توسعه‌ها اکنون ۱۲۸ اجرا و ۱۲٬۸۰۰ دوره است. ۹ نتیجهٔ مرجع در مقایسهٔ نمونه‌گیری دوباره استفاده شدند و نباید به تعداد اجراهای جدید اضافه شوند. لاگ خودآزمایی واقعی مدل‌ها و پیش‌پردازش روی ویندوز نیز PASS دارد. آموزش تازه‌ای برای طرح فعلی لازم نیست.

۱. بستهٔ به‌روزشده را برای مخزن نهایی استفاده کن. Complete-Tonight.ps1 اکنون به‌طور پیش‌فرض فقط نتایج موجود و چک‌های کوچک را بررسی می‌کند؛ شروع آموزش مجدد نیازمند گزینهٔ صریح -RunSampling است. رسید validation_receipt_local.json را از پوشهٔ کد نگه دار و بفرست تا چک کامل بسته هم ثبت شود.

۲. طبق explanation_study/START_HERE_FA.md ابتدا ۱۲ ارزیابی انسانی و سپس سه داوری واقعی ۲۴موردی را در سه گفت‌وگوی تازه با یک مدل ثابت انجام بده. پاسخ‌ها و نام واقعی مدل در رابط کاربری را ثبت کن. هیچ فایل خالی به‌عنوان نتیجه پذیرفته نیست.

۳. مخزن کد را تحت حساب خودت Public کن و لینک را بفرست. README و فایل‌های کد/خروجی‌های تجمیعی همراه باشند؛ دادهٔ خام، NPZ، checkpoint، cache و اطلاعات ورود در Git نباشند. اسکریپت Publish-Repository.ps1 برای مخزن خالی خودت آماده است و فقط با -Push انتشار انجام می‌دهد. دسترسی باید بدون ورود بررسی شود.

۴. منابع اخلاق واحد، صفحهٔ Overall Goal and Assessment Criteria و اعلان احتمالی دربارهٔ تغییر نمره به ۳۰ را بفرست. فایل رسمی موجود همچنان ۴۰ نمره را مشخص می‌کند.

## معیار تمام‌شدن امشب

- انجام‌شده: نتایج core، حساسیت ظرفیت/حلقه/مرتبه و نمونه‌گیری مجدد تأیید شده‌اند؛
- باقی: پاسخ‌های واقعی LLM و ۱۲ بررسی انسانی با مشخصات اجرا؛
- باقی: URL عمومی مخزن دانشجویی و رسید چک کامل بسته؛
- باقی: منابع اخلاق و اعلان‌های لازم برای نگارش گزارش.

نمونه‌های اتریوم از یک منبع‌اند و همهٔ هویت‌های مثبت، از جمله ۴۶۸ مثبتِ تست، مشترک‌اند. آن‌ها سه دیتاست مستقل نیستند. نتیجهٔ اصلی پنج‌seed اتریوم جدا از خلاصهٔ سه‌seed در هر نمونه گزارش می‌شود.

## برنامهٔ فردا

متن اصلی حدود ۹ صفحه در قالب ACL: معرفی/توجیه، هر چهار دادهٔ اصلی، روش و نتایج بازتولید، ساخت دادهٔ جدید، نتایج و حساسیت‌ها و داوری توضیحات، اخلاق، محدودیت‌ها و جمع‌بندی. ارجاعات خارج از سقف ۱۰ صفحه‌اند. گزارش باید URL عمومی مخزن، نمونهٔ واقعی داده و تفاوت پروتکل‌ها را داشته باشد. نتیجهٔ اصلی C=2 باقی می‌ماند؛ C=5 صرفاً حساسیت ثانویه است.
